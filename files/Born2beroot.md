# 🏰 Born2beroot — Системное администрирование

> **Полное название:** Born2beRoot  
> **Версия:** 5.2  
> **Тема:** Настройка сервера на виртуальной машине (VirtualBox/UTM)  
> **Тип:** Системное администрирование (не Python!)

---

## 🧠 Суть Проекта

Ты создаёшь свой **первый сервер** на виртуальной машине. Устанавливаешь операционную систему (Debian или Rocky Linux) и настраиваешь его по строгим правилам безопасности. **Графический интерфейс запрещён** — только командная строка.

---

## 📋 Обязательная Часть

### Выбор ОС
- **Debian** (последняя стабильная версия) — **рекомендуется** для новичков
- **Rocky Linux** (последняя стабильная версия) — сложнее

> ⚠️ **Нюанс:** На защите тебя спросят **почему** ты выбрал именно эту ОС. Подготовь сравнение Debian vs Rocky.

### Запрещено
- ❌ Графический интерфейс (X.org, Wayland и т.д.) — **оценка 0**
- ❌ Снепшоты на начало оценки (каждая оценка — с чистого листа)

---

### Разделы диска (Partitioning)

- Минимум **2 зашифрованных раздела** с использованием **LVM**
- Схема разделов будет проверяться на оценке

> ⚠️ **Нюанс:** LVM (Logical Volume Manager) — система управления дисковым пространством. Позволяет **динамически** менять размеры разделов. Важно понимать разницу между физическими (PV), логическими (LV) и группами томов (VG).

---

### Настройка SSH

- SSH-сервис должен работать **только на порте 4242**
- Подключение по SSH **от root запрещено**

> ⚠️ **Нюанс:** Почему не порт 22? Безопасность через obscurity — не идеальная защита, но затрудняет автоматизированные атаки на стандартный порт.

---

### Файрвол

- **UFW** (для Debian) или **firewalld** (для Rocky) — должен быть активен при загрузке
- Открыт **только порт 4242**

---

### Hostname

- Формат: `<твой_логин>42` (например, `avagyan42`)
- Во время защиты могут попросить **изменить** hostname

---

### Политика паролей

| Правило | Значение |
|---|---|
| Срок действия | Истекает каждые **30 дней** |
| Минимальное время между сменами | **2 дня** |
| Предупреждение | За **7 дней** до истечения |
| Минимальная длина | **10 символов** |
| Требования | Заглавная буква, строчная, цифра |
| Запрещено | > 3 **последовательных** одинаковых символа |
| Не содержит имя пользователя | Да |
| Минимум новых символов при смене (не для root) | **7** |

> ⚠️ **Нюанс:** Настройка через `/etc/login.defs` (сроки) и `/etc/pam.d/common-password` с модулем `pam_pwquality` (сложность). Для Rocky — через `authselect`.

---

### Sudo (строгая конфигурация)

| Правило | Описание |
|---|---|
| Попытки пароля | Макс. **3 попытки** |
| Сообщение об ошибке | Кастомное сообщение при неправильном пароле |
| Логирование | Все команды (ввод и вывод) в `/var/log/sudo/` |
| TTY режим | Включён (`Defaults requiretty`) |
| Пути | Ограничены: `/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin:/snap/bin` |

> ⚠️ **Нюанс:** `requiretty` запрещает использовать sudo из скриптов/cron без терминала. Это мера безопасности.

---

### Пользователи и группы

- Твой пользователь должен быть в группах **user42** и **sudo**
- На защите могут попросить **создать нового** пользователя с правильной политикой паролей

---

### Мониторинг-скрипт (`monitoring.sh`)

Bash-скрипт, который каждые **10 минут** (через `cron`) выводит на **все терминалы** (через `wall`) следующую информацию:

| Информация | Команда-подсказка |
|---|---|
| Архитектура ОС и версия ядра | `uname -a` |
| Количество физических процессоров | `grep "physical id" /proc/cpuinfo \| sort -u \| wc -l` |
| Количество виртуальных процессоров | `grep "^processor" /proc/cpuinfo \| wc -l` |
| Оперативная память (использовано/всего) | `free -m` |
| Дисковое пространство (использовано/всего) | `df -h` |
| Загрузка CPU | `top -bn1 \| grep "Cpu"` |
| Дата последней перезагрузки | `who -b` |
| Активен ли LVM | `lsblk \| grep "lvm"` |
| Активные TCP-соединения | `ss -t \| grep ESTAB \| wc -l` |
| Количество залогиненных пользователей | `who \| wc -l` |
| IPv4 и MAC-адрес | `hostname -I`, `ip link` |
| Количество команд sudo | `grep "COMMAND" /var/log/sudo/sudo.log \| wc -l` |

#### Пример вывода
```
#Architecture: Linux wil 4.19.0-16-amd64 #1 SMP Debian ... x86_64 GNU/Linux
#Physical CPU: 1
#vCPU: 1
#Memory Usage: 74/987MB (7.50%)
#Disk Usage: 1009/2Gb (49%)
#CPU load: 6.7%
#Last boot: 2021-04-25 14:45
#LVM use: yes
#TCP Connections: 1 ESTABLISHED
#User log: 1
#Network: IP 10.0.2.15 (08:00:27:51:9b:a5)
#Sudo: 42 cmd
```

> ⚠️ **Нюанс:** На защите попросят **объяснить, как работает скрипт** и как его **остановить без модификации** (подсказка: `crontab -e` и закомментировать или `systemctl stop cron`).

### Получение signature
```bash
# Linux:
sha1sum YourVM.vdi

# Mac:
shasum YourVM.vdi

# UTM (Mac M1):
shasum rocky.utm/Images/disk-0.qcow2
```

> ⚠️ **КРИТИЧНО:** Сигнатура **изменится** при следующем запуске VM! Сделай **копию** VDI-файла или используй **snapshot** для каждой оценки.

> ⚠️ **КРИТИЧНО:** Виртуальную машину **нельзя** добавлять в Git! Только `signature.txt`. Если сигнатуры не совпадут — **оценка 0**.
