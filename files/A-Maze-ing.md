## 🧠 Суть Проекта

Написать **генератор лабиринтов** на Python, который:
1. Генерирует лабиринт по конфигурации
2. Выводит результат в **файл** и **визуально** (терминал или MiniLibX)
3. Находит **кратчайший путь** от входа до выхода
4. Упаковывается как **переиспользуемый Python-пакет** (pip-installable)

## 📋 Обязательная Часть

### Конфигурационный файл

Программа принимает **конфигурационный файл**, описывающий параметры лабиринта:
- Размер (ширина × высота)
- Позиция входа и выхода
- Сид (seed) для воспроизводимости
- Флаг `PERFECT=True/False` (см. ниже)

> ⚠️ **Нюанс:** Формат конфигурации — **на твой выбор**, но он должен быть полностью описан в README.

### Типы лабиринтов

| Тип | `PERFECT` | Описание |
|---|---|---|
| **Идеальный** (perfect) | `True` | Единственный путь между любыми двумя точками. Без петель |
| **Игровое поле** (default) | `False` | Нет тупиков (кроме паттерна "42"), несколько маршрутов |

> ⚠️ **Нюанс:** «Идеальный лабиринт» = **остовное дерево** графа. Это прямая связь с **теорией графов**!

### Паттерн "42"

Лабиринт должен содержать **скрытый паттерн "42"** из стен — узнаваемый визуально. Это ячейки со **всеми четырьмя стенами** (тупики разрешены только для этого паттерна).

### Выходной файл

Файл с закодированными стенами каждой ячейки:
- Каждая ячейка = **4-битное число** (NESW — North, East, South, West)
- `1` = стена есть, `0` = стена убрана
- Шестнадцатеричная запись: `0`-`F`
- Первая строка — заголовок (ширина, высота, вход, выход)
- Решение (путь от входа к выходу) — последняя строка, буквами N/E/S/W

> ⚠️ **Нюанс:** Каждая **общая стена** должна быть закодирована **одинаково** у обеих соседних ячеек. Например, если ячейка (0,0) не имеет восточной стены, то ячейка (1,0) не должна иметь западной. Проверочный скрипт `maze_analyzer.py` это контролирует.

## 🧮 Алгоритмы Генерации (выбери один)

| Алгоритм | Описание | Сложность |
|---|---|---|
| **Recursive Backtracker** (DFS) | Идёт вглубь, откатывается при тупике | Простой, длинные коридоры |
| **Prim's Algorithm** | Растущее дерево из случайных рёбер | Средний, разветвлённый |
| **Kruskal's Algorithm** | Объединение множеств (Union-Find) | Средний, равномерный |
| **Eller's Algorithm** | Построчный, экономный по памяти | Сложный |

> ⚠️ **Нюанс:** Для **идеального** лабиринта все эти алгоритмы строят **остовное дерево** (spanning tree) — гарантируя единственный путь. Для **неидеального** нужно **убрать дополнительные стены** после генерации.

### Поиск кратчайшего пути
- **BFS** (Breadth-First Search) — гарантирует кратчайший путь в невзвешенном графе
- Или **A*** — если хочешь оптимизацию с эвристикой
